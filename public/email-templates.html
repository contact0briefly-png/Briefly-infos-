BRIEFLY.INFOS E-mails Transactionnels Supabase
Modèles d'e-mails HTML modernes, responsives et rédigés en français professionnel prêts pour la console Supabase.
📍 Procédure dans le tableau de bord Supabase :
1. Ouvrez votre console Supabase → Allez dans le menu latéral Authentication → Email Templates (ou Templates).
2. Sélectionnez l'onglet correspondant (indiqué sous le titre de chaque modèle).
3. Cliquez sur « Copier le sujet » et collez dans le champ Subject.
4. Cliquez sur « Copier le code HTML » et collez dans le champ Body (ou basculez en vue HTML/Source).
5. Cliquez sur Save changes en bas de page pour enregistrer.
